# 第二把椅子 · v0.2.1

一款关于忠诚、权力和猜忌的单人浏览器政治讽刺卡牌游戏。你和 3 名电脑争夺机构、征收利益、举报同僚，在 12 轮后争取党的二号继承席位。

## 阅读指南

- 第一次游玩，先看“开始游玩”和“怎么玩”，或直接进入游戏的新手引导。
- 开发维护参考“工程验证”和“文件导航”；当前进度与尚未验证的边界分别在 `ROADMAP.md` 和 `docs/VERIFICATION.md`。

## 开始游玩

直接打开 [在线游戏](https://lulueric.github.io/lulu_blog/games/second-chair/)，也可从 [博客介绍页](https://lulueric.github.io/lulu_blog/2026/09/12/second-chair/) 进入。在线版无需安装 Node.js；发布记录和验收边界见 `docs/VERIFICATION.md`。

本地开发与预览：

在项目目录运行：

```powershell
node scripts/serve.mjs
```

然后在电脑浏览器打开 [本地游戏](http://127.0.0.1:4173)。Windows 也可双击 `start.cmd`；启动器先寻找系统的 Node.js，再寻找当前用户的 Codex 内置运行时。

需要 Node.js 22 或更高版本，已在本机 v24.19.0 验证。没有需要安装的第三方依赖。服务仅监听本机地址，保持启动窗口运行；在该窗口按 Ctrl+C 停止。端口已被占用时，先检查现有页面；也可临时设置 `$env:PORT=4174` 再启动。

不能直接双击 `index.html`，浏览器原生模块需要通过本地 HTTP 服务加载。

## 怎么玩

目标先记一句：**通过最终审查，在第 12 轮结束时拥有最高宠幸。**

| 数值 | 先理解什么 |
| --- | --- |
| 宠幸 | 元首的信任，决定生死和最终名次 |
| 影响力 | 打牌、任命机构的预算；本轮峰值太高会招猜忌 |
| 忠诚 | 组织的评价，提高每轮影响力收入 |

第一次进入会先显示三页入职简报，阅读期间电脑暂停。选择“带我完成一次行动”后，依次认识自己的数值、查看一张真实可用的手牌、确认行动并结束。可以跳过，也可随时在右上角“新手引导”重看，不会重开当前对局。

首次遇到机构、轮末结算、弃牌、猜忌与调查时，会说明用途、代价和下一步。自己的数值名称可点击解释；精确公式与特殊规则在“玩法说明”中展开查看。

- 首轮先手由会议编号决定，之后每轮轮换。电脑先手时等待它完成行动。
- 点击手牌查看总费用和双方效果，选择目标及需要交出的牌后确认。普通行动每次轮到自己最多两次；机密档案不占行动、限一次，挡箭牌在受袭时使用。
- 点击无主机构，以 5 影响力接受任命；下一轮起提供收入。同系统成套再加 1，每人最多持有 3 处。
- 影响力越高越容易引起猜忌；界面显示本轮峰值与预计宠幸损失。花掉影响力不能抹去峰值。
- 每轮基础损失 5 宠幸，再加猜忌。强力宣传净耗 2 影响力获得 6 宠幸；集体颂词自己 +10、其他存活者各 +1。
- 宠幸低于 20 进入调查。公开检讨、交权或自保卡可以补救；完整行动机会结束时仍未达标则被清洗。
- 结束行动时超过 7 张牌，需要点击选择弃牌。没有必要用完全部行动。
- 12 轮后先完成轮末结算、处理清洗，再按宠幸和忠诚决出胜者。新版极端表忠即时消耗忠诚，不再赊欠宠幸；旧会议的既有欠款仍需偿还。

页面右上角可查看完整玩法说明；卡牌档案包含全部 16 种卡牌及总成本。秘密交易允许选择自己的换出牌；机密档案可以在行动次数用完后换牌；受袭时可选择拦截或接受损失。电脑行动可加速。低于常规桌面宽度时手牌可横向滚动，页面可纵向滚动。

进度自动保存在当前浏览器；刷新后继续，包括尚未决定的受袭回应。引导进度单独保存；旧会议升级会保留原始存档项及既有欠款。新会议会先提示替换存档。同版本、同会议编号与相同操作可复现对局；不同浏览器或端口不共享存档。

## 工程验证

```powershell
node --test
node scripts/simulate.mjs 500
node scripts/simulate.mjs 1000 --symmetric
node scripts/audit-cards.mjs 300
node scripts/audit-favor.mjs 300
```

所有模拟都会检查每次动作后的数值范围、牌数守恒、调查状态和终局条件；不通过时以非零状态退出。

`--symmetric` 让所有座次使用同一种策略。`audit-cards.mjs` 另外统计各牌可用时的选择率、前后期使用、弃牌与实际拦截；它描述现有电脑策略，不能代替人工平衡测试。

`audit-favor.mjs` 统计满值频率、逐轮宠幸、调查与自救，并逐局核对宠幸收支守恒。加 `--source <项目目录>` 可用同一统计脚本检查保留的旧版源码，规则和电脑均从该目录加载；对照方法与结果见 `docs/FAVOR_BALANCE.md`。

## 版本管理

源码、测试、规则和开发脚本统一保存在 [博客仓库的游戏目录](https://github.com/LuLuEric/lulu_blog/tree/main/games/second-chair)。克隆仓库后进入 `games/second-chair/` 即可运行上述命令。查看 `git log -- games/second-chair` 可追踪游戏变更；本地编辑区通过显式发布清单同步，临时文件、原始存档和发布备份不上传。版本变化见 `CHANGELOG.md`。

本地服务器与测试使用 [Node.js HTTP 标准库](https://nodejs.org/docs/latest-v24.x/api/http.html)及 [Node.js 测试运行器](https://nodejs.org/docs/latest-v24.x/api/test.html)。浏览器存档使用 [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)。
